# AngelECHO: interactive hero concept

A scroll-driven hero concept for **AngelECHO**, a human-like AI voice agent by AngelPBX. Designed and built by [2WIK](https://www.2wik.design).

**Live:** this repository is published with GitHub Pages.

- Four scenes: glass voice sphere → voice ring → intent mesh → back to the sphere.
- Left alone, it plays the story on a seamless loop; scroll or swipe to take control.
- Click the sphere or **Talk to ECHO** to try a live browser voice demo (Chrome or Edge, microphone required). Without a mic it plays a sample call.

This repository contains the built static site only.
